================================================================================
[도로대장 시설물 조사옵션] 엑셀 수정 및 자동 변환 완벽 가이드
================================================================================

본 문서는 현장조사용 모바일 웹앱(index.html) 및 PC 도면 편집기(map-editor.html)에서
사용되는 시설물 종류, 감지 레이어, 입력 속성 등을 엑셀에서 쉽게 수정하고
프로그램에 적용하는 방법을 설명합니다.


--------------------------------------------------------------------------------
1. 전체 동작 흐름 한눈에 보기
--------------------------------------------------------------------------------
(1) [엑셀 수정]
    '도로대장_시설물_조사옵션_템플릿.xlsx' (또는 사용자가 작성한 엑셀 파일)을 열어
    시설물 목록, 옵션, 색상 등을 수정하고 **저장 후 엑셀 창을 닫습니다**.

(2) [원클릭 변환 실행]
    '엑셀변환_실행.bat' 파일을 마우스로 **더블클릭**합니다.
    화면에 파일 선택 창이 뜨면 수정하신 엑셀 파일을 선택해 줍니다.
    (※ 다른 이름의 엑셀 파일인 경우에도 원하는 파일을 직접 고르실 수 있습니다.)

(3) [웹앱에서 즉시 확인]
    변환이 끝나면 'facility-config.js' 파일이 자동 갱신됩니다.
    브라우저(index.html 또는 map-editor.html)에서 키보드의 [Ctrl + F5]를 눌러
    새로고침하시면 변경된 시설물 목록과 조사 옵션이 즉시 나타납니다.


--------------------------------------------------------------------------------
2. 엑셀 파일 실행 및 선택 방법 (3가지 방식 지원)
--------------------------------------------------------------------------------
[방법 A] 마우스 더블클릭 (가장 추천!)
  - '엑셀변환_실행.bat'을 마우스로 더블클릭합니다.
  - 윈도우 파일 선택 창이 자동으로 열립니다.
  - 변환하고자 하는 엑셀 파일을 마우스로 클릭하고 [열기]를 누르면 끝납니다.
  - 만약 창을 닫거나 취소하면 폴더 내의 기본 템플릿 파일이 자동으로 변환됩니다.

[방법 B] 마우스 드래그 앤 드롭 (가장 간편!)
  - 변환하고자 하는 엑셀 파일 아이콘을 마우스로 끌어다가(Drag)
    '엑셀변환_실행.bat' 아이콘 위에 툭 떨어뜨리면(Drop),
    파일 선택 창 없이 해당 파일이 즉시 1초 만에 변환됩니다.

[방법 C] 파이썬 직접 실행 (명령어 창)
  - 터미널이나 CMD(명령 프롬프트)에서 아래 명령어를 실행할 수 있습니다:
    python convert_excel_to_config.py
    (또는 python convert_excel_to_config.py "원하는파일명.xlsx")


--------------------------------------------------------------------------------
3. 엑셀 템플릿 수정 규칙 및 작성 요령
--------------------------------------------------------------------------------
※ 엑셀을 편집하실 때 다음 규칙만 지켜주시면 프로그램 오류 없이 완벽 작동합니다.

(1) 시트 이름:
    - 반드시 시트 탭 이름이 [ 시설물_조사옵션 ] 이어야 합니다.

(2) 데이터 행 위치:
    - 1행 ~ 4행: 제목 헤더 및 안내 설명 영역입니다. (지우지 마세요)
    - 5행부터: 실제 시설물 데이터가 한 줄씩 작성됩니다.
    - 시설물 순서를 바꾸거나 새로운 시설물을 맨 아래 행에 추가하셔도 됩니다.

(3) 열(컬럼)별 작성 요령:
  ┌──────┬────────────┬────────────────────────────────────────────────────────┐
  │  열  │  컬 럼 명  │                     작 성  규 칙                       │
  ├──────┼────────────┼────────────────────────────────────────────────────────┤
  │ A열  │ 시설물명   │ 앱에 표시될 시설물 고유명칭 (예: 가로등, 보호가드레일) │
  │      │            │ ※ 빈칸으로 두면 해당 행은 변환 대상에서 제외됩니다.   │
  ├──────┼────────────┼────────────────────────────────────────────────────────┤
  │ B열  │ 감지레이어 │ 도면(DXF)에서 이 시설물로 자동 판별할 레이어 이름.     │
  │      │            │ 여러 개인 경우 쉼표(,)로 구분 (예: R_LIGHT,ROAD_LIGHT) │
  │      │            │ 💡 [글자색 팁]: B열 글자색을 파란색 계열로 지정하면    │
  │      │            │    기둥에 다른 표지판을 붙일 수 있는 '주 시설물'로     │
  │      │            │    자동 인식되어 부속시설물 결합이 가능해집니다.       │
  ├──────┼────────────┼────────────────────────────────────────────────────────┤
  │ C열  │ 캐드레이어 │ 캐드로 내보낼 때 생성할 레이어명 (예: 가로등_T)        │
  │      │            │ ※ 비워두면 자동으로 [시설물명_T]로 생성됩니다.        │
  ├──────┼────────────┼────────────────────────────────────────────────────────┤
  │ D열  │ 색상       │ 캐드 표준 ACI 색상 번호 (1=빨강, 2=노랑, 3=초록,       │
  │      │            │ 4=하늘, 5=파랑, 6=분홍, 7=흰색 등). 숫자만 입력       │
  ├──────┼────────────┼────────────────────────────────────────────────────────┤
  │ E열  │ 접두어     │ 캐드 텍스트 앞에 붙을 머리말 (예: 가로등)              │
  │      │            │ ※ 비워두면 시설물명이 기본 적용됩니다.                │
  ├──────┼────────────┼────────────────────────────────────────────────────────┤
  │ F열~ │ 조사 옵션  │ 현장에서 선택하거나 입력할 세부 제원 항목들            │
  │      │ (세부필드) │ (아래 작성 양식 참조)                                  │
  └──────┴────────────┴────────────────────────────────────────────────────────┘

(4) F열 이후 조사 옵션(속성 필드) 표기 양식:
  ① 목록 선택형 (드롭다운 메뉴):
     형식: 항목명[선택지1, 선택지2, 선택지3]
     예시: 형식[외팔형, 양팔형, 일자형]
     설명: 괄호 안의 첫 번째 항목('외팔형')이 앱 실행 시 기본값으로 자동 선택됩니다.

  ② 숫자 입력형 (기본값 제공):
     형식: 항목명[숫자: 기본값]
     예시: 수량[숫자: 1],  높이[숫자: 8.5]
     설명: 스마트폰에서 숫자 키패드가 열리며, 지정한 기본값이 미리 채워집니다.

  ③ 텍스트 직접 입력형:
     형식: 항목명[직접입력]  또는  그냥  항목명
     예시: 비고[직접입력],  관리번호
     설명: 자유롭게 글자를 입력할 수 있는 텍스트 상자로 생성됩니다.

  💡 [스마트 키워드 안내]:
     항목명에 '지주' 또는 '사진'이라는 글자가 들어가 있으면,
     주 시설물에 부속 시설물을 추가로 결합할 때 불필요하게 기둥이나 사진을
     중복해서 묻지 않도록 시스템이 자동으로 걸러주는 똑똑한 필드로 동작합니다.


--------------------------------------------------------------------------------
4. 주의사항 및 오류 해결 (FAQ)
--------------------------------------------------------------------------------
Q1. 파이썬 실행 시 "PermissionError: [Errno 13] Permission denied" 에러가 납니다.
  → 엑셀 파일이 컴퓨터에 열려 있는 상태에서 파이썬을 실행하면 발생합니다.
    작업 중이던 엑셀 창을 **반드시 저장 후 완전히 닫은 뒤** 다시 실행해 주세요.

Q2. 엑셀을 수정하고 변환했는데 웹앱 화면에 반영이 안 됩니다.
  → 웹 브라우저(크롬/사파리)가 이전 화면(캐시)을 기억하고 있어서 그렇습니다.
    키보드의 [ Ctrl + F5 ] (강력 새로고침)를 누르시거나,
    스마트폰에서는 브라우저 캐시를 지우고 새로고침해 주시면 바로 적용됩니다.

Q3. 파이썬이 설치되어 있지 않다는 오류가 날 경우
  → 컴퓨터에 파이썬 3.8 이상이 설치되어 있어야 하며,
    엑셀을 읽기 위한 openpyxl 라이브러리가 필요합니다.
    (명령 프롬프트에서: pip install openpyxl 입력하여 설치)
